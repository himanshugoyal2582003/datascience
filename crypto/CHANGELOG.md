# Changelog

All notable changes to the Crypto Fraud Intelligence project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-28

### Added
- ✨ Initial release of Crypto Fraud Intelligence system
- 🎯 End-to-end fraud detection pipeline
- 📊 Interactive Next.js dashboard with real-time visualizations
- 🔌 FastAPI REST backend deployed on Render
- 📈 Power BI executive dashboard
- 🔄 KNIME ETL workflow for data processing
- 📓 Jupyter notebooks for data analysis
- 🧪 Comprehensive test suite (backend + frontend)
- 📚 Full documentation and deployment guides
- 🔒 MIT License
- 🤝 Contributing guidelines
- ⚙️ CI/CD pipeline with GitHub Actions

### Features
- 🔍 Transaction risk scoring and anomaly detection
- 📊 Fraud network visualization
- 👥 Community detection and centrality analysis
- 💾 CSV-based data pipeline (PostgreSQL ready)
- 🌐 RESTful API with automatic Swagger documentation
- 📱 Responsive dashboard UI
- 🎨 Interactive charts and graphs

### Documentation
- README with quick start guide
- API documentation with Swagger
- Deployment guide (Render + Netlify)
- Dataset documentation
- KNIME workflow guide
- Contributing guidelines
- Security policy
